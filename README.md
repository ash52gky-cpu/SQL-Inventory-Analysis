# 📊 SQL Inventory & Sales Analytics

## 📌 Project Overview
This project contains end-to-end SQL scripts designed to analyze warehouse inventory valuation, generate low-stock alert notifications, and evaluate sales performance using advanced SQL concepts (JOINs, CASE statements, aggregate functions, and Window Functions like `RANK()`).

## 🛠️ Tech Stack
- **Database Engine:** PostgreSQL / MySQL
- **Tool Used:** DB Fiddle / GitHub
- **Language:** SQL

## 📈 Key Insights Derived
1. Identified high-value inventory categories in Spain-based logistics operations.
2. Automated critical stock reorder thresholds to prevent stockouts.
3. Ranked top revenue-generating warehouse products.
